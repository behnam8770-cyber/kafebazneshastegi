# کافه بازنشستگی — نسخه ۲

این نسخه نسبت به نسخه اول یک گام کامل‌تر است و علاوه بر صفحه اصلی، ساختار یک رسانه واقعی را شبیه‌سازی می‌کند.

## فایل‌ها
- index.html — صفحه اصلی
- article.html — صفحه اختصاصی مطلب
- category.html — آرشیو مطالب
- publisher.html — «اتاق انتشار» برای تولید بسته شبکه‌های اجتماعی
- style.css — هویت بصری و طراحی واکنش‌گرا
- script.js — تعاملات
- assets/logo.png — لوگوی اصلی

## قابلیت‌های اضافه‌شده
- ساختار چندصفحه‌ای
- صفحه مقاله با اشتراک‌گذاری تلگرام و واتساپ
- آرشیو مطالب
- جست‌وجوی اولیه
- افزایش اندازه متن
- طراحی موبایل‌محور
- اتاق انتشار و تولید نمونه بسته انتشار برای تلگرام، اینستاگرام، ایکس و شبکه‌های داخلی

## توجه
اتاق انتشار در این نسخه «نمونه رابط کاربری» است. برای انتشار واقعی باید در مرحله بعد به یک CMS و ذخیره‌سازی محتوا متصل شود تا بدون ویرایش کد، مطلب منتشر شود.

## انتشار رایگان
ساختار پروژه برای Cloudflare Pages یا GitHub Pages مناسب است و می‌توان دامنه kafebazneshastegi.ir را در مرحله انتشار به آن متصل کرد.
